## 1. 背景与范围

`ezr-demo` 是 swarm-ezr2 仓库中的终端演示程序：以 ratatui 绘制多任务下载器界面，模拟 HTTP / BT 两类任务的分块并发下载过程（速度、对端连接等运行数据为确定性模拟生成）。

本需求文档覆盖七轮迭代中**全部 UI 布局与交互需求**，包括：

- 面板布局与对齐（顶部区、任务详情、任务队列、流量图）；
- 并发连接（并发明细）面板的新增与逐步细化；
- 键盘 / 鼠标交互（明细选择、断开连接）；
- 数据展示口径（累计量、状态可见性、IP 隐私掩码）；
- 动效质量（速度防闪烁）与像素级流量图。

**不在范围内**：下载引擎核心调度逻辑（分块租约演进、任务状态机内部实现）、QA 脚本内部实现细节。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 头部面板 | 顶部「ezr download」标题面板（3 行） |
| 任务队列面板 | 头部下方展示分块队列与下载槽位的面板（3 行） |
| 流量图 | 右上角无边框的全局速度走势图（单色面积图：八级部分块亚字符精度绘制，全图仅一种颜色） |
| 任务详情面板 | 右列展示选中任务详细信息的面板 |
| 并发连接面板 | 任务详情下方、按连接逐行列出并发明细的面板（本文亦称「并发明细」） |
| BT / HTTP 任务 | BitTorrent 协议任务（有上传）/ HTTP 协议任务（无上传） |
| 掩码 IP | 对端地址隐私化显示：中间段以 `*` 隐藏，仅保留首段与末端 |
| 累计量 | 单条连接自「本次开始下载」起累计的下载/上传字节 |
| 盲文点阵 | Unicode Braille Patterns（U+2800–U+28FF），每字符格表示 2×4 点阵（四～七轮使用，第八轮起改用块元素） |
| 实心竖线 | U+2588 全块字符 █，每字符列一条竖线、相邻列共享端点行（第八轮中期方案，同轮被 REQ-8.4 重设计取代） |
| 八级部分块 | U+2581–U+2588（▁▂▃▄▅▆▇█），每字符行的 1/8 分级填充，用于面积图亚字符精度顶线（REQ-8.4 定稿口径） |

## 5. 最终定稿 UI 规格

### 5.1 整体布局

屏幕垂直分为：**顶部带 5 行（头部仪表面板通栏全宽）→ 主体带（弹性）→ 页脚 4 行**。

宽终端（图表开启）：

```
┌─ ◆ EZR Downloader  v0.1.0-m1 ──────────────────── 通栏全宽（100%）────────┐
│ 并发 38  会话已下载 231 MB  全局 ↓30 ↑2  峰值 ↓31 ↑3 │  ▂▃▅          │
│ ─────────────────────────────────────────  │ ████（单色面积）20%   │
│ 正在下载 (10) │ 已完成 (4) │ 下载槽位 5/5    │ ▄▆█                      │
├─ 下载任务 ─────58% ──────┐┌─ 任务详情 ─────42% ──────────────────────────┐
│ ▶ sintel-720p   [下载中]  ││ 状态 / 大小 / 速度 / 分块 …（恰 9 行内容）   │
│   arch-2025     [做种中]  │├─ 并发连接 ────────── 活跃 7/12 ──────────┤
│   …（占左列全高）         ││ IP        下载速度 累计下载 上传速度 累计上传│
│                           ││ 185.*.92   230 KB/s  1.4MB   39 KB/s 249KB  │
│                           ││ 15cd:*:97a6 …（占右列余下全部高度）          │
└───────────────────────────┘└──────────────────────────────────────────────┘
┌─ 页脚：快捷键 + 鼠标提示 + toast ──────────────────────────────────────┐
└─────────────────────────────────────────────────────────────────────────┘
```

- 顶部带 5 行：头部仪表面板**通栏全宽**（右缘 = 屏幕右缘 = 任务详情面板右缘），内容三行 = 字段单行 / 分割线 / 页签行；字段区与图区之间以 **│ 竖线分隔符**（贯通全高）分割，图区**左右各留 1 列空白**，右侧内嵌无边框单色面积流量图（占内容区全高、宽 20%）。
- 「任务队列」面板已撤销（第七轮）：页签与槽位计数并入头部（第八轮：槽位内联左对齐、紧跟「已完成」页签并以 │ 分隔），任务列表自头部正下方起、占满左列全高。
- 主体带：左列 **58%** = 任务列表（占满全高）；右列 **42%** = 任务详情（11 行，自主体带顶部起）+ 并发连接面板（占余下全部高度）。
- 窄终端 / 关闭图表（G 键）**预期降级**：头部、任务列表全部满宽（宽度天然一致）；流量图与并发明细面板不渲染。
- 页脚窄屏逐级精简快捷键提示（< 100 列截 9 项、< 86 列截 7 项、< 72 列截 5 项）。

### 5.2 顶部带（5 行，通栏头部仪表面板）

#### 5.2.1 头部面板「ezr download」（REQ-2.1 + REQ-5.2 + REQ-6.1/6.2/6.3 + REQ-7.1）

- 宽度**通栏全宽 5 行**（标题边框行 + 字段行 / 分割线 / 页签行 3 内容行 + 底边框；第七轮定稿），**右缘 = 屏幕右缘 = 任务详情面板右缘**。
- **标题行**：`◆ EZR Downloader` + 版本号（峰值**不再**写在标题行边框线上——REQ-6.1）。
- **字段行（内容行 1，REQ-7.1 单行排列）**，顺序固定：
  **并发**（全局并发连接数 = 处于「下载中/做种中」状态任务的连接总数）→ **会话已下载** →
  **全局** ↓/↑ 速度 → **峰值** ↓/↑（会话内速度历史最大值，**写在面板内容里**；峰值 ↓ 淡蓝与曲线同色，兼作图例）。
- **分割线（内容行 2）**：横向 `─` 贯通字段区宽、止于 │ 分隔符；图区让位给波形不画线（REQ-7.3）。
- **│ 竖线分隔符（REQ-8.3，第八轮）**：字段/分割线/页签区与流量图之间，贯通头部内容区全高；分隔符左右（字段区侧/图区侧）各有 1 列空白，图区右缘再留 1 列空白。
- **页签行（内容行 3）**：见 5.2.2。
- 图表关闭 / 窄终端时分割线与页签行贯通全宽，字段行不变。
- 基线的「并发线程、任务、正在下载、已完成」4 字段维持移除口径（正在下载/已完成 以页签形式存在于页签行）。

#### 5.2.2 页签行（原「任务队列」面板并入，REQ-7.3，第七轮定稿）

- **「任务队列」面板整体移除**（分块队列示意一并撤销），其内容并入头部面板内容行 3：
  **正在下载 (n) │ 已完成 (n) │ 下载槽位 x/y**（活动页签黑字青底加粗高亮，`Tab` 切换；第八轮 REQ-8.1：下载槽位**内联左对齐**、紧跟「已完成」页签并以 │ 分隔，不再右对齐行尾；已满黄色加粗：等待任务需排队）。
- 任务列表自头部正下方起、**占满左列全高**（58%）；窄终端 / 关闭图表时满宽。
- 点击选中任务、滚轮滚动等列表交互不受影响（页签仅 `Tab` 键切换）。

#### 5.2.3 单色面积流量图（REQ-1.3 → REQ-2.2 → REQ-5.1 → REQ-6.3/6.4 → REQ-8.2/8.4/8.5，定稿口径）

- **内嵌头部面板内部右侧**（第七轮定稿）：**无边框、无标题**，占内容区全高（3 行）、宽度 = 内容区 **20%**（REQ-7.2 较第六轮 40% 减半；并保证字段区 ≥92 列，不足时压缩图宽，≥6 列才渲染）；第八轮 REQ-8.3：与字段区之间以 **│ 竖线分隔符**（贯通全高）分割，图区**左右各留 1 列空白**。
- 绘制方式（REQ-8.4 形状 + REQ-8.5 单色，第八轮定稿）：**单色面积图**——逐列自底向上填充，每字符行按 **1/8 分级**（▁▂▃▄▅▆▇█ 八级部分块）呈现亚字符精度的平滑顶部曲线；**全图统一一种颜色** = 下载淡蓝 RGB(122,185,242)（与「下载中」状态色及「峰值 ↓」图例同色；REQ-8.5：不用好几种颜色，发光渐变方案退役）；普通等宽字体即可显示，**无需盲文字体**（一～七轮的方块/盲文点阵方案与八轮中期整格 █ 竖线方案均退役）。
- **单序列：仅绘制下行流量（下载淡蓝单色）；上传流量不绘制**（REQ-6.4、REQ-8.5）。
- **无断列无间隔（REQ-8.4 核心）**：面积图自底向上填充 → **每列均有墨、首尾相接、无任何间隔**——平缓段呈横向连贯面积，陡坡段呈竖向块列，顶部曲线以八级部分块平滑过渡、波形连续无断列；序列先经**双向 EMA 平滑**（前向 + 反向，α=0.75）抑制单采样毛刺，再按窗口 **min–max 自适应缩放**（上下各留 ≈15% 呼吸边距，下限取窗口峰值 5%）使波形纵贯全部 3 行——不退化为单行直线；每列取**双子样本较大值**（保尖峰）。
- 采样：取最近 2×(列数+1) 个样本（速度历史上限 180 样本）；v2.0 起 **y=0 基准线移除**（纯下行曲线）。
- **波形数据源（REQ-7.4 配套）**：模拟器新增**共享带宽多尺度波动**——全局带宽因子 = 1 + 0.11·sin(2πt/6.5s) + 0.05·sin(2πt/2.1s) + 0.03·sin(2πt/1.1s)（±19% 连续起伏，模拟真实共享带宽），叠加每任务每帧 ±8% 抖动；全局速度曲线连续波动，波形真实生动（列表/详情/并发明细同步体现）。
- 图例：头部内容行「峰值 ↓」淡蓝与曲线同色，兼作图例（REQ-8.5 单色口径）。
- 按 `G` 关闭图表后进入紧凑布局（头部与列表满宽），再按恢复。
- 演进记录：右列底部大面板（基线）→ 移至详情上方与队列同高（一轮）→ 通高 6 行带框（二轮）→ 盲文点阵带框（四轮半）→ 无边框 21%×3 行（五轮）→ 内嵌头部面板右侧 40%（六轮）→ 手工盲文点阵真折线、宽 20%（七轮）→ 实心竖线无间隔阶梯折线（八轮中期）→ 发光渐变面积图（八轮 REQ-8.4）→ **单色面积图：八级部分块亚字符精度 + 全图仅一种颜色（八轮定稿，REQ-8.5）**。

### 5.3 任务列表（基线保持）

位置：主体带左列（58%）。交互保持基线：↑↓ 选择、点击选中、Tab 页签、Space/R/A/D/U/J/C 等任务操作（见 6.3）。任务列表选中行的深青色背景高亮为全局选中色标准。

### 5.4 任务详情面板（REQ-1.1 + REQ-5.3）

- 内容区**恰为 9 行**；面板总高 11 行（9 行内容 + 上下边框）。
- 各任务状态（排队/校验/失败/下载/做种等）的信息字段行数均不超过 9 行，恰好完整显示。
- **第五轮上移**：面板自主体带顶部起（与「任务队列」同排），填补流量图宽度减半后右下方的空缺；由此右列的并发明细面板获得 3 行额外高度。

### 5.5 并发连接面板（并发明细）—— 核心

位置：右列、任务详情正下方，**占右列余下全部高度**（44 行终端下含边框 24 行、内容 22 行——12 条演示连接一屏尽览；34 行终端下含边框 14 行、内容 12 行，超出时以「… 共 N 条 · 滚轮翻看」提示，滚轮 / Ctrl+↑↓ 滚动翻看）。面板标题「并发连接」。

#### 5.5.1 可见性状态门槛（REQ-3.1）

只有「正在下载（下载中）」与「做种中」任务显示明细，其余状态一律空面板：

| 任务状态 | 明细内容 | 活跃计数 |
|---|---|---|
| 下载中 | 逐连接明细 | 活跃 x/N |
| 做种中 | 逐连接明细（仅上传方向活跃） | 活跃 x/N |
| 等待中 / 已暂停 / 校验中 / 后期处理中 / 已失败 / 已完成 | 「（无并发连接）」居中提示 | 0/0 |

实现口径（验收需知）：

- **渲染层门槛**而非数据层清除：状态下沉时连接数据冻结隐藏，恢复下载时原样续用——保证「暂停/继续、断点续传不清零累计量」的口径不被破坏。
- 明细为空或未选中任务时，面板**不接收滚轮**（滚轮穿透滚动任务列表）。
- 交互守卫优先级：状态门槛 toast **先于** 协议（BT/HTTP）toast。

#### 5.5.2 列定义与排序（REQ-1.4、REQ-2.3、REQ-4.1）

**BT 任务——五列**（单空格分隔，总宽 47 列）：

| 列序 | 列名 | 宽 | 对齐 | 说明 |
|---|---|---|---|---|
| 1 | IP | 11 | 左 | 对端地址掩码显示（规则见 5.5.3） |
| 2 | 下载速度 | 8 | 右 | 待命显示 `-` |
| 3 | 累计下载 | 8 | 右 | 本次开始下载起算 |
| 4 | 上传速度 | 8 | 右 | 待命显示 `-` |
| 5 | 累计上传 | 8 | 右 | 本次开始下载起算 |

**HTTP 任务——三列**（总宽 22 列）：

| 列序 | 列名 | 宽 | 对齐 | 说明 |
|---|---|---|---|---|
| 1 | 序号 | 4 | 右 | 1 基编号 |
| 2 | 下载速度 | 8 | 右 | 待命显示 `-` |
| 3 | 累计下载 | 8 | 右 | 本次开始下载起算 |

- HTTP 任务**无上传两列**（表头与数据行均无），BT 任务有——表头随协议自适应。
- 排序：**BT 按连接建立顺序（槽位序）**；**HTTP 按序号（1 基）升序**。
- 全部列对齐均做 **CJK 宽字符感知**（中文按 2 列计宽）。
- 数值格式：速度 ≤ `9.9 MB/s` 尺寸、累计量 ≤ `999.9 MB` 尺寸，精确容纳列宽。

#### 5.5.3 IP 掩码规则（REQ-4.1，定稿口径）

仅 BT 任务的明细首列显示掩码 IP；HTTP 任务保持序号列。

| 协议族 | 原始地址示例 | 显示 |
|---|---|---|
| IPv4 | `192.168.2.100` | `192.*.100` |
| IPv6 | `2001:0db8:85a3:0000:0000:8a2e:0370:7334` | `2001:*:7334` |

规则细则：

- 判别：地址含 `:` 视为 IPv6，否则 IPv4。
- IPv4 显示 `<首段>.*.<末端>`（最长 9 字符）；IPv6 显示 `<首段>:*:<末端>`（最长 11 字符）。
- 中间段一律以 `*` 隐藏，**不允许任何完整 IP 泄露**（QA 正则断言）。
- 列宽取 11（可容纳最长 IPv6 掩码），左对齐（标识符语义）。
- 演示数据生成：由 **(任务 id, 连接槽位)** 确定性哈希生成——同一任务同一槽位的对端地址在重建分块、断点续传后保持不变；约 1/5 为 IPv6（8 组 4 位十六进制全形）；IPv4 首段取 1..=223、末段取 1..=254（避开保留/组播段）。
- 连接完成当前块领取新块时，IP **保持不变**（原地改写传输区间）。

#### 5.5.4 累计量口径（REQ-1.4）

- **累计下载**：自「本次开始下载」起，该连接实际落盘的字节。
- **累计上传**（仅 BT）：自「本次开始下载」起，按活跃连接均摊并独立抖动后累计。

清零 / 保留规则：

| 事件 | 累计量 | 口径 |
|---|---|---|
| 失败后按 R 重试 | **清零** | 新的一次下载 |
| 已暂停任务重新排队后再启动 | **清零** | 新的一次下载 |
| 新建任务首次开始下载 | 从零累计 | 新的一次下载 |
| 暂停后直接继续（服务器支持断点续传） | 保留 | 同一次下载的延续 |
| 单块完成、连接领取新块 | 保留 | 同一次下载的延续 |
| 服务器不支持断点续传，继续/重试从头下载 | **清零** | 等价新的一次下载（有明确 toast 提示） |

#### 5.5.5 活跃计数与溢出滚动

- 面板标题右侧显示 **「活跃 x/N」**：活跃 = 下载速度或上传速度 > 0 的连接数，N 为当前明细总连接数。
- 连接数超出面板可视高度：滚轮 / Ctrl+↑↓ 滚动翻看；底部提示行显示翻看提示（如「… 共 N 条 · 滚轮翻看」），未裁剪时显示快捷键提示。

#### 5.5.6 配色

| 元素 | 颜色 |
|---|---|
| 下载速度 / 累计下载 | 淡蓝（与头部 ↓、流量图下行曲线一致） |
| 上传速度 / 累计上传 | 品红（与头部 ↑、流量图上行曲线一致） |
| 待命值 `-` | 暗灰 |
| 表头 / 次要信息 | 暗灰 |
| 选中行 | 深青背景 + 白字（同任务列表选中色） |

### 5.6 页脚（基线保持 + 增补快捷键）

两行：快捷键行 + 鼠标提示 / toast 行。完整快捷键见 6.1/6.3。

## 6. 交互规格

### 6.1 键盘——本迭代新增

| 键 | 行为 | 需求 |
|---|---|---|
| `Ctrl+↑` / `Ctrl+↓` | 并发明细选中行上移 / 下移 | REQ-2.4 |
| `Ctrl+B` | 断开选中的连接（**仅 BT 任务**），该行从屏幕移除 | REQ-2.4 |

**Ctrl+↑/↓ 细则：**

1. 仅明细可见（下载中 / 做种中）时生效；否则 toast 提示「当前状态无并发明细（仅下载中/做种中可选）」。
2. 选择位置上下边界钳制，不越界。
3. 选中行超出可视范围时自动跟随滚动保持可见。
4. 切换选中任务后，明细选择自动复位。
5. 选中行以深青背景高亮、首列白字。

**Ctrl+B 断开细则：**

1. 状态门槛同上（toast「当前状态无可断开的并发连接（仅下载中/做种中）」），且先于协议判断。
2. HTTP 任务尝试断开：toast 拒绝（仅 BT 支持断开）。
3. 断开 = 该连接从明细中移除；toast 显示被断开连接的**掩码 IP**：「✂ 已断开连接 185.*.92（剩余 11 条）」。
4. 被断开连接未完成的分块视为**「由其他节点补完」**：块队列照常推进、任务仍可完成，进度前跳 ≤ 1 块（GB 级任务下不可见）。
5. 断开后其余连接的 IP 保持不变，选中索引钳制到有效范围。
6. 连接全部断开后，任务速度归零。

## 7. 数据与动效规格

### 7.1 速度防闪烁（REQ-2.5）

| 层级 | 规则 |
|---|---|
| 连接下载 / 上传速度 | 围绕均摊值 ±12% 抖动 + EMA 平滑（新值 0.55 / 旧值 0.45） |
| 任务级聚合速度 | ±18% 抖动 + EMA（0.6 / 0.4） |
| 连接领取新块 | 速度**不再归零**，沿用末速自然收敛 |
| stalled / 空连接 | 瞬时归零（显示 `-`） |

目标：消除速度数字逐帧跳变与「-」单帧闪现；渲染节奏保持 100ms 不变。

### 7.2 上传模型（BT）

- 上传按**活跃连接均摊**，每连接带独立抖动；做种中同样分摊上传。
- HTTP 任务无上传维度（不显示、不累计）。

### 7.3 演示数据边界

- 每任务并发连接数上限 12（演示值）。
- 连接采用分块连接模型：每条连接负责一段连续字节区间，完成当前块后领取新块。
- 速度、IP 等均为确定性模拟生成（见 5.5.3），非真实网络数据。

## 11. 附录

### 11.1 IP 掩码算法（伪代码）

```text
mask_ip(ip):
    if ip 包含 ':':                      # IPv6
        first = ip 按 ':' 切分的第 1 段   # 例 2001:0db8:... → 2001
        last  = ip 按 ':' 切分的最后 1 段 # 例 ...:0370:7334 → 7334
        return "{first}:*:{last}"         # 2001:*:7334
    else:                                # IPv4
        first = ip 按 '.' 切分的第 1 段   # 192.168.2.100 → 192
        last  = ip 按 '.' 切分的最后 1 段 # 192.168.2.100 → 100
        return "{first}.*.{last}"         # 192.*.100
```
