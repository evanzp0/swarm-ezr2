## 1. 设计原则

| # | 原则 | 落地方式 |
|---|------|----------|
| P1 | **lazygit 式聚焦显示** | 永远只有一个视觉焦点：聚焦面板边框绿色加粗，其余面板暗边框；浮层打开时所有底层面板统一降级暗框 |
| P2 | **模态浮层** | 对话框 / pieces / 帮助窗口均为模态：按键与鼠标事件先交给浮层，浮层关闭后才回到主界面 |
| P3 | **交互说明收敛于帮助窗口** | 主界面页脚 = 行 1 快捷命令 chips（A/D/M/Q/H，可点击，本轮需求修订恢复）+ 行 2 toast 反馈；各面板/弹窗内容区**不设**操作提示行，全部交互说明按分类收纳在 H 帮助窗口 |
| P4 | **颜色即语义** | 状态色、协议徽标、分块色块全系统统一（见 §2、§8）；同一语义永远同一颜色 |
| P5 | **键盘鼠标双通道等价** | 每个键盘操作都有鼠标等价物（切面板/切页签/选行/确认按钮/复制字段/关闭弹窗），反之滚动/拖拽仅鼠标提供 |
| P6 | **CJK 安全** | 全部对齐、截断、命中区域按终端显示宽度计算（CJK 记 2 列）；浮层边界切在宽字符半格时由渲染层 `clip_wide_at_edges` 缓冲区级清扫防残影（不清屏、无闪烁） |
| P7 | **小终端可用** | 面板/弹窗在小于设计尺寸时钳制尺寸、收缩网格行数，不越界不崩帧 |
| P8 | **通用组件一致性** | 列表行为（选择/翻页/滚动/滚动条）与弹窗行为（模态/边框/拖拽/Esc）全系统共用同一套契约（§4）；padding 执行统一三档体系（§4.3）；新增列表或浮层必须复用同一规范并过 §4.4 清单核对，不允许私自发明交互或另定 padding |
| P9 | **通用滚动条单一实现** | 滚动条渲染/命中/拖拽全部收敛在 `src/scrollbar.rs`（引擎）+ `src/scrollable_panel.rs`（`ScrollablePanel` 面板封装，ScrollbarMode = None/Vertical/Horizontal/Both 四态，§4.2）：不同 panel 复用同一实现获得同一行为——双线滑块 `═`/`║` 在单线轨道 `─`/`│` 上滑动（两端 ←→/↑↓ 箭头），滑块拖拽滚内容、箭头点击·按住连发、轨道翻页、方向键滚动；不允许任何 panel 私自另画滚动条 |
| P10 | **窗口不需要有提示信息**（本轮需求修订定版） | panel/弹窗内容区内**不渲染操作提示/快捷键图例**：添加/修改对话框、删除对话框、pieces、帮助、字段值弹窗底部均无提示行；操作反馈走 toast（§7.4），交互说明唯一入口 = H 帮助窗口（P3）。页脚例外（本轮需求修订：chips 恢复保留）：行 1 快捷命令 chips 是**可点击的命令入口**（鼠标等价通道，非提示文案）、行 2 toast 是反馈通道——二者为页脚既定功能，不属于提示信息（§5.5） |
| P11 | **窗口右上角关闭按钮**（本轮需求修订定版） | 全部弹窗（添加/修改/删除/pieces/帮助/关于/字段值）顶边框行右端统一绘制 **[✗]** 关闭按钮（§4.2.3）：悬停高亮、按压高亮、原地松开关闭（拖出取消）——每个窗口都有常驻可见的鼠标关闭通道，不依赖提示行告知 |
| P12 | **统一 padding 体系**（本轮需求修订定版） | panel 与弹窗内容区执行统一三档 padding：S1 边框附着元素前后各 1 空格 / S2 内容区左右各 2 列、上下各 1 行 / S3 层次缩进 2 列步进（§4.3）；新增面板/窗口不得私自另定 padding，特例仅限 §4.3 特例表 |

| `MAGENTA` | `Rgb(214,112,214)` | 做种中、上传 ↑ |
| `GREEN` | `Green` | 已完成、校验通过 |
| `WHITE` + `BOLD` | — | 任务名、选中行名称、删除确认中的任务名 |
| `EMPTY` | `Rgb(54,68,74)` | 进度条空轨道 `░`、未下载分块兜底色 |

### 2.2 视觉语法约定

- **边框**：全部 `BorderType::Rounded`（圆角 `╭ ╮ ╰ ╯`）；边框/标题颜色成对跟随焦点状态。
- **徽标**：`[协议]` 黄色、`[状态]` 状态色（§8）。
- **进度条**：整体进度条不分块：`█` 填充（状态色）+ `░` 空轨道（EMPTY）。
- **占位符**：输入框空值显示 DIM2 占位文本（如 `https://example.com/file.zip`）。
- **下拉指示**：`▾` 表示可展开；选中项 `▸` 前缀 + DarkGray 反底。
- **动画**：校验中/后期处理中行内 braille 转轮 `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`（100ms 步进）。

## 3. 全局布局

三段式纵向布局（`ui::draw`）：

```
┌ 头部仪表面板 ─────────────────────── Constraint::Length(5) ┐
├ 主区（任务列表 | 任务详情+并发连接） ── Constraint::Min(8)  ┤
└ 页脚（双行：chips + toast）────────── Constraint::Length(4) ┘
```

三种布局形态：

| 形态 | 触发条件 | 主区结构 |
|------|----------|----------|
| **标准双栏** | 终端宽 ≥ 100 列且 `show_panes = true`（默认） | 左列 58% = 任务列表；右列 42% 上 = 任务详情（定高 12 行），下 = 并发连接（占余高度，`Min(6)`） |
| **紧凑模式** | 宽终端按 `G` | 详情/并发面板收起，任务列表占满主区；焦点强制回列表 |
| **窄终端** | 宽 < 100 列 | 头部无流量图（分割线与页签行贯通全宽），列表占满整行；焦点钳制为列表 |

> 焦点钳制双保险：`!wide || !show_panes` 时渲染入口直接把 `focus` 置为 `Panel::List`，
> 与 `G` 键处理逻辑一致。

### 3.1 图层结构（z-order 与绘制顺序）

每帧在同一个缓冲区上按**固定自底向上的顺序**绘制（后绘者覆盖先绘者）：

| 层 | 内容 | 说明 |
|----|------|------|
| L0 底层 | 头部仪表面板 → 任务列表 → 任务详情 → 并发连接（紧凑/窄终端只绘列表） | 每帧全量重建 |
| L1 页脚 | 行 1 命令 chips + 行 2 toast | 每帧全量重建 |
| L2 对话框 | 添加/修改（HTTP(S) 与 BT 两族）/删除（含内嵌下拉） | 覆盖层：`Clear` 清出自身矩形后绘制 |
| L2+ 命令窗口 | 命令窗口（A；与对话框互斥，按键层保证） | 同上 |
| L3 pieces | 分块状态弹窗 | 同上；与对话框互斥（按键层保证） |
| L4 帮助 | 帮助窗口 | 同上 |
| L5 关于 | 关于窗口（About） | 同上 |
| L6 字段值 | 字段值弹窗（点击详情字段值，§6.8） | 最上层；同上（各浮层互斥，按键层保证） |

- **下拉浮层**（校验算法/选择代理）在所属对话框内容之后绘制，覆盖对话框与
  底层内容（L2 内部的子覆盖层）。
- 每个浮层渲染前先 `Clear` 清出自身矩形，再立即执行 `clip_wide_at_edges`
  清扫边界半格宽字符（残影根治点，§4.2.3），然后绘制边框与内容——
  前后帧模型自洽，增量 diff 直接输出，**任何图层翻转都不清屏**（§9）。
- **位置记忆回填模型**：对话框/pieces/帮助打开时居中，渲染层首帧把实际
  左上角回填到 `dialog_pos` / `pieces_pos` / `help_pos` / `about_pos`；此后拖拽改写该位置、
  渲染时钳制在终端内。帮助/关于跨次打开仍记忆，pieces/对话框关闭即清。
- **命中矩形回填**：每帧渲染时同步重建全部可点击区域（`tab_rects` /
  `footer_cmd_rects` / `dlg_*_rects` / `detail_*_rect` / `conns_area` /
  `list_area`），鼠标判定永远基于本帧真实几何（布局变化零延迟）。

## 4. 通用组件

系统内多处界面呈现相同的行为模式。本章把两类高频模式提炼为**通用组件规范**：
凡"条目多于一屏需要浏览"的场景都是**列表**（§4.1），凡"叠加在主界面之上的模态窗口"
都是**弹窗**（§4.2）。各具体 Panel / 窗口（§5、§6）只描述自身差异，共性一律引用本章。

> 代码说明：通用性体现在**同一套设计契约与口径**（lazygit 式），并非同一个渲染函数；
> 新增列表/浮层时以本章为准绳实现，保持全系统交互一致。

### 4.1 通用列表组件（List）

#### 4.1.1 定位与使用者

| 实例 | 归属 | 形态 |
|------|------|------|
| 任务列表 | 主界面左列（§5.2） | A 可选择列表 |
| 并发连接明细 | 主界面右列（§5.4） | A 可选择列表 |
| 下拉选项（校验算法/代理） | 弹窗内（§6.4） | A 可选择列表（小列表） |
| pieces 分块网格 | pieces 弹窗（§6.5） | B 纯滚动内容 |
| 帮助内容 | 帮助窗口（§6.6） | B 纯滚动内容 |
| 字段值内容（本轮需求修订） | 字段值弹窗（§6.8） | B 纯滚动内容 |

两种形态：

- **A 可选择列表**：条目即选中单元，支持选中高亮 + ↑↓ 移动 + 视口跟随；
- **B 纯滚动内容**：无选中概念，只维护视口（pieces 网格、帮助文本）。

#### 4.1.2 状态模型

每个列表实例独立维护以下状态（互不共享）：

| 字段 | 含义 |
|------|------|
| `total` | 条目总数（任务数 / 连接数 / 选项数 / 网格行数 / 文本行数） |
| `selected` | 选中下标 0 基（仅形态 A） |
| `scroll` | 视口起始（A 以条目为单位，B 以行为为单位） |
| `visible` | 可视条目数/行数（ui 层每帧回填，键盘翻页步长依赖它） |
| `last_selected` | 上一帧选中下标（变化检测，防滚动锁死，见 4.1.6） |

#### 4.1.3 UI 规范

**选中高亮**（形态 A）：

- 默认样式：选中行整块 `SEL_BG` 深青背景，名称白色加粗；
- **可见性策略**（两处列表刻意不同）：
  - 任务列表：选中行**恒定显示**（与面板焦点无关）——主列表是全局上下文，右侧详情/并发明细跟随它；
  - 并发连接：选中行**仅本面板聚焦时显示**——非聚焦面板不显示内部选中态，保证视觉焦点唯一（lazygit 口径）；
  - 下拉选项：`▸` 前缀（ACCENT）+ 白字加粗 + DarkGray 反底。

**滚动条（通用滚动条组件，m3 修订——引擎唯一收敛于 `src/scrollbar.rs`，
面板封装 = `src/scrollable_panel.rs` 的 `ScrollablePanel`）**：

> 滚动条不再是各 panel 私画的字形，而是全系统唯一的通用组件：渲染、几何、
> 命中测试、拖拽反解全部在引擎内实现；**panel 一律经由 `ScrollablePanel`
> 使用**——组件画边框并返回内框，内容由各 panel 自绘，最后
> `render_bars` 按 `ScrollbarMode`（None/Vertical/Horizontal/Both）叠画
> 滚动条并回填命中几何（显示条件 `total > page` 在组件内收口）。
> **不同 panel 使用相同组件获得完全相同的行为**（设计原则 P9）。本节
> 描述组件契约，实例差异见 §4.1.7。

- **位置与方向**：
  - 垂直 = 画在所属面板/弹窗的**右边框列**；
  - 水平 = 画在**下边框行**（m3 新增，并发连接面板超宽时出现）。
- **显示条件**：`total > page` 且轨道 ≥ 2 格——水平面板宽 ≥ 10（2 角 + 2×2 留白
  + 2 箭头 + 2 轨道）、垂直面板高 ≥ 6（2 角 + 2 箭头 + 2 轨道，垂直不留白），
  否则不绘制（轨道过小的极矮/极窄面板退化为滚轮/键盘滚动）；
  几何变化（如协议切换 BT↔HTTP、终端缩放）时组件随帧重建，命中区域零延迟。
- **字形组合**（分轴向：水平 = 左/右角 + 留白 + 箭头 + 留白 + 轨道/滑块 +
  留白 + 箭头 + 留白 + 右角；垂直 = 箭头紧贴角与轨道、不留白，同列/同行对齐）：
  滑块用双线字符 `═`（水平）/ `║`（垂直）——**可滑动部分**，在与面板边框同
  字形同粗细的**单线轨道** `─` / `│` 上滑动：

  ```
  垂直（右边框列，紧贴不留白）：   水平（下边框行，箭头前后各 1 格空白）：

  ╮   ← 右上角                    ╰ 空白 ← 空白 ═══─── 空白 → 空白 ╯
  ↑   ← 顶部箭头（DIM，紧贴 ╮）
  │   ← 轨道（DIM2，与边框同粗细单线）  （单行：左角 + 留白 + 左箭头 + 留白 +
  ║   ← 滑块（双线，加粗，在轨道上滑动）     ═ 滑块 + ─ 轨道 + 留白 + 右箭头 +
  ↓   ← 底部箭头（DIM，紧贴 ╯）             留白 + 右角）
  ╯   ← 右下角
  ```

- **留白（分轴向规则）**：**水平**箭头**前后两侧**各留 **1 格空白**（真留白，
  覆盖原边框线/轨道区）——外侧靠边框线（角）、内侧靠轨道，即
  `╰ 空白 ← 空白 ═══─── 空白 → 空白 ╯`；**垂直箭头紧贴角与轨道、不留白**
  （`╮↑│║│↓╯`）——垂直边框列必须连续（中断的竖线在视觉上等同边框破损），
  且垂直空间金贵，去掉四格留白后轨道显著更长（同等板高下轨道 +4 格）。
  水平留白格不参与命中测试（纯视觉），不占角字符（╰ ╯ 共存）。
- **几何算法**（垂直/水平同一套公式，沿轴换元；留白分轴向）：
  - `track = 轴向可绘格数 − 2×外侧留白 − 2 箭头 − 2×内侧留白`
    （水平减 2×1×2 格留白；垂直无留白 = 轴向格数 − 4）；
  - `thumb_h = clamp(round(page/total × track), 1, track)`，且 `max_pos > 0`
    时再钳到 ≤ track−1（**行程保证**：内容可滚则滑块必可动，行程 ≥ 1）；
  - 滑块位置**顶/底（左/右）端吸附**：`pos = 0` 贴头箭头内侧（水平 = 头侧
    留白之后、垂直 = 紧贴 ↑）、`pos ≥ total − page` 末页贴尾箭头内侧；
  - 中间按比例取整：`thumb_at = round(pos/max_pos × travel)`，
    `travel = track − thumb_h`；round 保证「滑块位置 → 滚动偏移」的反函数
    （拖拽用）与正向严格互逆，拖拽手感与显示一致。
- **滑块颜色 = 所属面板边框色**：主界面面板聚焦 → `FOCUS_BORDER` 绿加粗，
  未聚焦 → `BORDER` 暗色；弹窗内（pieces/帮助）恒 `FOCUS_BORDER`；
- **滑块 = 双线字符 `║`/`═`**（水平为连续 `═` 段），加粗显示、在单线轨道
  `│`/`─`（与面板边框同字形同粗细）上滑动，与居中的轨道/箭头同列/同行对齐。

**滚动条交互契约**（全部实例同一口径；此前「有的箭头能点、有的拖拽移动窗口」
的不一致已随组件化根治）：

| 操作 | 行为 |
|------|------|
| 按住滑块 `═║` 拖拽 | **比例滚动内容**（滑块在单线轨道上滑动 = 移动视口，不移动浮层窗口——修复：pieces/帮助里拖滚动条此前按「窗口拖拽」处理） |
| 单击箭头 `↑↓←→` | 沿箭头方向步进 1 单位（单位 = 该 panel 的滚动单位：任务条目/连接行/内容列/网格行/文本行） |
| **箭头按压高亮** | 按下/按住 = **前景色换成滑块同款**（thumb_color：聚焦绿 + 加粗，**无背景色**）；按住期间指针拖出箭头 = 取消高亮（连发不中断）、拖回恢复；松开后 400ms 余辉（快速单击也有可见点击效果） |
| **按住箭头不放** | 自动连发：0.4s 起振、0.12s 周期（App::tick 驱动），松开即停 |
| 单击/按住轨道 | 朝点击方向**整页滚动**（页长 = 可视单位数），可按住连发 |
| 键盘方向键 | 面板聚焦时 ↑↓ 纵向（A 形态列表 = 选择跟随视口，§4.1.6；B 形态 = 直接滚动）；**←/→ 横向滚动**（m3，并发连接面板超宽列） |

- 松开左键（任何位置）即结束拖拽/连发；事件内立即钳制 0..=max_pos，末页即停。

#### 4.1.6 滚动跟随与防锁死（时序契约）

三个触发源、两种语义，严格分离：

1. **键盘选择 / 页签切换 / 总数钳制** → `scroll_to_selection()`：视口跟随选中项；
2. **鼠标滚轮** → 只改 `scroll`：视口自由移动，选中项不动；
3. **每帧 tick 兜底**：
   - 仅当 `last_selected ≠ selected`（选中项真的变了）才调用 `scroll_to_selection()`；
     若滚轮滚动也触发跟随，视口每帧被拉回选中行——滚动条锁死、无法浏览全表（历史 bug 的根因与修复）；
   - `scroll` 钳制 ≤ `total − visible`（末页不空滚）；
   - 并发连接列表同口径，另加：切换选中任务时 `scroll`/`selected` 归零重置；
     **滚轮向下同样在事件内立即钳制**（到底即停，同任务列表口径）——否则
     越界窗口先渲染出底部空白行、下一帧才被 tick 钳回，反复触发即闪烁；
     渲染层另将起点钳到「最后一个满窗」（`len − rows`），连接数收缩的
     过渡帧也不产生空白行（双重防线）。

#### 4.2.2 模态规则

- **按键优先级**：关于窗口 > 帮助窗口 > pieces > 字段值弹窗 > 对话框（含下拉）> 主界面；浮层打开时按键先交给最上层浮层，主界面快捷键（A/M/D/P/Q…）全部失效、由浮层自行消费或忽略；

#### 4.2.3 UI 规范

- **边框**：**恒定**绿色加粗圆角框（`panel_border_style(true)`）+ 绿色加粗标题
  （`panel_title_style(true)`）——与主面板聚焦色统一。删除确认框亦为绿框，
  危险语义由正文与按钮承载，不用红色边框；
- **几何**：设计尺寸固定（各实例见 §6）；渲染时钳制 `min(设计尺寸, 终端尺寸)`，
  位置钳制在终端内（四边不出界）；内框低于最小宽/高时放弃内容渲染（只留边框）；
- **内容区 padding（本轮 padding 统一）**：按 §4.3 三档体系执行——内容区
  左右各 2 列、上下各 1 行（S2）；特例仅限 §4.3 特例表（下拉浮层高度
  「项数+2」紧凑特例、居中型窗口以居中实现内边距）；
- **打开定位**：打开时终端居中（渲染层首帧回填位置）；
- **位置记忆**：pieces / 帮助 / 关于支持拖拽且记忆位置（帮助/关于跨次打开仍记忆，pieces 关闭即清；字段值弹窗同为关闭即清）；
  对话框每次打开重新居中（不跨次记忆）；
- **右上角 [✗] 关闭按钮**（本轮需求修订）：全部弹窗统一在**顶边框行右端**
  绘制 `[✗]`（✗ = U+2717 BALLOT X 单列宽；**中括号内紧凑、不留空格**；
  `[✗]` 3 列宽，右角符内侧留 1 列边框 padding、`[✗]` 左侧再留 1 列——
  不覆盖边框线；padding 取 1 列 = 与面板标题「 任务详情 」自身首尾 1 空格
  padding 同构，整体占用 5 列；热区仅 `[✗]` 自身 3 列，padding 列不参与
  点击）；**中括号 `[`/`]` 与弹窗边框线同色（绿+粗，融入边框、不随悬停/
  按压变化、无任何高亮）**；高亮的只有 ✗：常态 DIM2、悬停/按压 = **仅
  前景色红+粗（无背景色/无反色）**；弹窗过窄或与标题重叠时放弃绘制；
  下拉浮层不设 [✗]（选择列表：Esc/点击外部收起）。
  按下/松开判定与关闭行为在 App 层（`popup_close_rect` / `x_press`），
  各弹窗鼠标分支关闭自身（关闭通道与各实例 Esc 同口径）；
- **CJK 残影防护**：每个浮层渲染前 `Clear` + `clip_wide_at_edges` 清扫边界半格宽字符，
  前后帧模型自洽，diff 直接绘制；**浮层翻转不清屏**（旧版 FNV-1a 签名 +
  `terminal.clear()` 全屏重绘已退役——清屏会在浮层出现/消失瞬间清空整个
  终端造成整屏闪烁，详见 §9）。

| **S1 边框附着元素** | 前后各 **1 空格** | 附着在边框线/标题行上的紧凑元素 | 面板标题 ` 任务详情 `、右上角徽标 ` x/y 项 ` / ` n/m 项 `、弹窗关闭按钮 [✗] 与边框线左右各 1 列 |
| **S2 内容区内边距** | 左右各 **2 列**、上下各 **1 行** | 一切 panel/弹窗的内容区（列表、表格、表单、正文、图例） | 任务列表（左 2 由光标槽承担、右 2 由内容宽收窄）；任务详情行首 2 列；并发明细左右 2 列；头部字段/页签行左 2 列；页脚 chips/toast 左右 2 列；字段值弹窗（VAL_PAD_X=2/Y=1）；对话框字段行 x+2；帮助内容区上下各 1 行；pieces 名称/元信息/图例/网格左右 2 列 + 上下各 1 行 |
| **S3 层次缩进** | 每级 **2 列** 步进 | 内容区基准之上的行内层次 | 帮助窗口组标题左 2 列（基准）、键位条目行左 4 列（基准 + 2） |

实现口径：

- **S2 左 2 列**：内容首列 = 面板/弹窗内框 x + 2；**S2 右 2 列**：内容可用宽 =
  内框宽 − 4（截断/折行预算必须按此计算，如详情字段值 `内框宽 − 13` =
  左 2 + 字段名 9 + 右 2）。
- **S2 上 1 行 / 下 1 行**：
  - **定版式弹窗**（添加/修改/删除对话框、pieces）：窗体高度设计时预留——
    内框 = 顶 1 + 内容 + 底 1；按钮行与字段区之间保留 1 空行。尺寸随历史
    对比：添加 74×11→**74×12**、修改 74×9→**74×10**、删除 66×6→**66×7**、
    pieces 64×19→**64×21**（字段行/按钮行 y 均不变，仅底部补齐）。
    本轮需求修订（网格呼吸行 + 加宽）：pieces 网格与上下相邻行之间再各空
    1 行、窗体加宽 3 列，64×21→**67×23**（网格仍 14 行，见 §6.5）；
    随后本轮需求修订（高度收缩 + 网格右扩）：窗体高度减少 3 行、分块网格
    右边增加 1 列，67×23→**68×20**（网格 11 行，见 §6.5）。
  - **滚动型窗口**（帮助）：窗体尺寸不变，内容渲染区上下各收 1 行
    （70×24 → 可视行 22→20）。
  - **居中型窗口**（关于）：内容以垂直/水平居中实现对称内边距，不再另设 padding。
- **选中行高亮背景满行**：行选中背景（SEL_BG）由 Paragraph 样式作用于整行
  区域绘制，padding 列同样覆盖——内容缩进不产生背景缺口（任务列表右 2 列
  收窄仅影响内容排版宽度）。

#### 4.4 新增 Panel / 窗口设计清单（本轮需求修订新增）

新增 panel 或窗口时，按以下清单逐项核对（同时是代码评审 checklist）。
**前 6 项为硬性规范，违例视为 bug**；后 6 项为一致性要求。

1. **边框与标题**：圆角框 `BorderType::Rounded`；标题 = ` X `（S1：前后各
   1 空格）；边框/标题色 = 聚焦绿加粗 / 未聚焦暗（`panel_border_style` /
   `panel_title_style`；浮层恒定聚焦色，§4.2.3）。
2. **右上角徽标**（如需）：` x/y 项 ` 口径（S1：前后各 1 空格；x = 实时
   条目数、y = 上限/总数），DIM 弱化（§5.4）。
3. **内容区 padding**：按 §4.3 S2（左右 2 列、上下 1 行）+ S3（层次缩进
   2 列步进）；特例仅限 §4.3 特例表，新增特例先入表。
4. **关闭按钮 [✗]**（弹窗必配，§4.2.3）：顶边框行右端，[✗] 3 列、与边框线
   左右各留 1 列；中括号 = 边框色不变、✗ 常态 DIM2 / 悬停·按压 = 红加粗；
   原地松开关闭、拖出取消；`app.popup_close_rect` 每帧回填热区。
5. **无提示信息**（P10）：panel/弹窗内容区内不渲染操作提示/快捷键图例；
   操作反馈走 toast（§7.4）；交互说明进 H 帮助窗口（`help_lines` 新增分组/
   条目）。页脚例外见 §5.5（chips = 命令入口、toast = 反馈通道）。
6. **模态语义**（§4.2）：打开时底层面板降级暗框（`overlay_open`）；Esc/q/Q
   关闭（Ctrl+C 全局例外）；点击窗口外部无操作；按键不透传主界面。
7. **滚动复用**：内容可滚动时必须复用 `ScrollablePanel`/`scrollbar` 通用
   组件（P9，§4.1.3），禁止私自画滚动条。
8. **鼠标等价**（P5）：键盘可操作的都有鼠标等价（选中/点击/拖拽/滚轮），
   命中热区每帧回填 App 字段（与渲染同步，含 padding 偏移）。
9. **CJK 安全**（P6）：全部对齐/截断/热区经 `w()`（CJK = 2 列、零宽 = 0）；
   浮层渲染前 `Clear` + `clip_wide_at_edges` 防残影。
10. **小终端可用**（P7）：尺寸 `min(设计尺寸, 终端尺寸)` 钳制；内框低于
    最小宽/高放弃内容渲染（只留边框），不 panic。
11. **定位与记忆**：打开居中；支持拖拽（按住空白处拖动、滚动条上拖拽 =
    滚内容，§4.2.5）；位置记忆口径按实例声明并写入 §4.2.6 速查表。
12. **回归脚本同步**：改动后同步 `scripts/verify_ezr.py` /
    `check_popup_integrity.py`（`rects_for`）等脚本的几何断言，并跑全量
    回归（含 `test_focus_style.py`、`verify_scrollbar_universal.py`）。

### 5.2 任务列表面板

标题 ` 下载任务 `，右上角标题 ` n/m 项 `（选中序号/过滤后总数，DIM；S1：前后各 1 空格）。

进度条右缘离右边框 2 列；选中背景仍满行，§4.3 实现口径）。

> 本面板是通用列表组件（§4.1）的**主实例**：选择/翻页/滚动/滚动条的全部行为
> 见 §4.1（任务列表行）。本节只描述任务条目自身的渲染。

**任务条目 = 3 行内容 + 1 行空行**（`ITEM_HEIGHT = 4`）：

```
▌ neovim-0.11.2.tar.gz  [HTTPS] [下载中]                    45.2%
  ████████████████████████░░░░░░░░░░░░░░░░░░░░░
  ↓ 12.5 MB/s  1.72/4.32 GB  剩余 05:12
```

| 行 | 内容与规则 |
|----|-----------|
| 行 1 | 光标 `▌`（选中时，ACCENT 加粗；未选中为空格）+ 名称（选中白色加粗，预算 `8..64` 列截断 `…`）+ `[协议]` 黄色 + `[状态]` 状态色 + 右对齐百分比（状态色加粗，宽度 5 补齐；离右边框 2 列，§4.3 S2）；**总大小未知（不支持续传的 HTTP(S) 流式下载，Task::size_known = false）显示 `?%`（占同宽列右对齐）** |
| 行 2 | 整体进度条（`█`/`░`，宽 = 内容宽 − 4 = 内框宽 − 6，状态色填充）；**总大小未知 + 下载中 = 走马灯滑块**（循环滑动色块：自左缘滑入、每帧 2 列匀速右移、右缘滑出后空一帧重新滑入，块长 = `clamp(宽/4, 4..8)`——进度条无法增长，以滑动表达「传输进行中、进度不可知」）；**总大小未知 + 其余状态 = 空轨道**（全 `░`，无进度语义）；校验中行尾追加 `SHA-256 分块校验 ⠋`（淡蓝）、后期处理中追加 `后期处理中 ⠋` |
| 行 3 | 按状态分版式（见下） |

行 3 状态版式：

- **已失败**（全红）：`重试 x/y · Ns 后重试｜不自动重试｜已达上限 · downloaded/total`
- **等待中**（黄）：`排队第 N 位 · 等待空闲下载槽位`（已获槽位则显示 `已获得下载槽位 · 即将开始`）+ ` · downloaded/total`
- **已完成**：`<算法> 校验成功`（绿）/ `校验失败`（红）/ `无校验`（DIM）+ ` · total`
- **做种中**：`↑ 速度`（品红）+ `seeders/peers` + `已上传 up/total` + `剩余做种 H:MM:SS`
- **BT 其余状态**：`↓ 速度 ↑ 速度  seeders/peers  x/y GB  剩余 ETA`（下载中取实际值；否则逐位 `-`，箭头保留）
- **HTTP 其余状态**：`↓ 速度  x/y  剩余 ETA`（缺失用 `-`）；**总大小未知时 `<已下载>/? B`、剩余 `-`**（速度正常显示）

**选中与聚焦**：选中行整块 `SEL_BG` 深青背景（与面板焦点无关、恒定显示，§4.1.3）；
面板聚焦边框绿色。

**空态**：居中显示 `（此页签下没有任务，按 A 打开命令窗口添加任务）`；面板过小显示 `（区域过小）`。

**活跃口径（本页重构）**：活跃并发 = 「**正在连接**」（Connecting，TCP/uTP
握手中，尚未传数据）或「**已经连接**」（Connected，握手完成、持有块在传）的
连接；「**已断开**」（Closed，块队列耗尽后自然退出）与待命连接**不显示**。
演示节奏：任务开始/续传下载时各连接槽位按序交错进入「正在连接」（握手耗时
0.2s 起、每个 +0.1s、上限 1.5s，速度列显示 `-`、不传数据），握手完成转
「已连接」开始跳动；下载临近结束时块队列耗尽，连接逐个自然断开——x 从
y 爬升/回落的全过程在面板上实时可见。头部全局「并发」字段同口径只统计
活跃连接。

> 本面板的明细区是通用列表组件（§4.1）实例：↑↓/翻页/滚轮/滚动条/跟随防锁死
> 全部行为见 §4.1（并发连接行）；滚动条为通用组件（§4.1.3）——本面板是唯一
> 同时拥有**垂直 + 水平**两根滚动条的实例。本节只描述列结构与数据语义。

**面板结构 = 表头 1 行 + 数据行**（无底部提示行，交互说明在帮助窗口）；
**数据区左右各留 2 列 padding**（本页重构：表头与数据行在面板内框基础上
左右各收 2 列，内容不顶格贴边框，与页脚/字段值弹窗阅读内边距同思路；
滚动/命中几何随数据区平移，点击语义不变）。

| 任务协议 | 列序（单空格分隔，显示列宽） |
|----------|------------------------------|
| BT | `IP`（11 列左对齐）· `下载速度` 8 · `累计下载` 8 · `上传速度` 8 · `累计上传` 8 · **`客户端`（6 列，m3 新增，末二列）** · **`协议`（4 列，m3 新增，末列）**（合计 59 列） |
| HTTP | `序号`（4 列）· `下载速度` · `累计下载`（无上传两列；合计 22 列，不超宽） |

规则：

- IP 掩码：IPv4 `192.*.100`、IPv6 `2001:*:7334`（首段+末段）。
- **客户端**（m3 新增）：对端客户端缩写，两个大写英文（演示池：`QB`=qBittorrent /
  `TR`=Transmission / `LT`=libtorrent / `UT`=µTorrent / `DE`=Deluge / `AR`=aria2 /
  `RT`=rTorrent / `TX`=Tixati / `AZ`=Azureus(Vuze) / `XL`=迅雷；按任务种子+槽位
  确定性生成，仅 BT 行渲染此列）。
- **协议**（m3 新增）：传输协议 `TCP`（直连）或 `uTP`（微传输协议/BT over UDP，
  约 1/3 概率）；仅 BT 行渲染此列。HTTP 任务列序不变（无这两列）。
- 速度待命显示 `-`（「正在连接」阶段速度列同为 `-`）；下载中任务的连接在
  已连接后恒显示下载速度（demo 造数路径首帧即有速度初值 = base_speed 均摊，
  不出现无传数据却显示 `-` 的空窗；首个采样点后由 1s 采样 EMA 接管）——
  下载速度淡蓝、上传速度
  品红（与头部全局字段同色）；客户端/协议列 DIM 弱化（标识信息，不与数据列
  争抢视觉）。
- HTTP `序号` = 连接在任务连接池中的**槽位号**（1 基，稳定不随断连重编号；
  活跃明细只显示活跃连接，已断开槽位的序号不出现——明细可能不连续）。
- **明细只显示活跃并发（本页重构）**：行数 = 右上角徽标的 x，滚动/选中
  （↑↓/点击）均以活跃明细行为准；B 断开选中行先映射回真实连接再移除。
- **横向滚动（m3 新增）**：BT 七列内容宽 59 列 > 数据视口宽（本页重构：内框
  48 列在明细左右各 2 列 padding 后 = 44 列）→ 内容被裁剪 + 底部出现**水平滚动条**
  （`← ─ ═ ─ →`，通用组件 §4.1.3）；`←`/`→` 键步进 2 列、滑块拖拽比例滚动、
  箭头点击/按住连发、轨道翻页。滚动上限 = 内容宽 − 视口宽 + 1（放宽 1 列：
  末列「协议」含宽字，停点与宽字前半格重叠时渲染按字符边界回退，末字
  「议」会永远差一格；放宽后滚到最右末列完整可见，滑块位置由组件按
  内容宽−视口宽钳制、不越界）。切任务/切协议时横向偏移归零重置。
  HTTP 任务内容不超宽 → 无水平滚动条。
- 选中行高亮仅在本面板聚焦时显示（§4.1.3 可见性策略）；任务列表选中不受影响。
- 仅「下载中」「做种中」任务的明细可选中/滚动（其余状态按 0 条处理并 toast 提示）；
  累计量 = 本次开始下载后的累计（重试/重新排队清零）；状态下沉时连接数据冻结隐藏。
- 切换选中任务时：滚动与选中行归零重置（§4.1.6，含横向偏移）。
- 空态：未选中任务时居中显示 `（未选中任务）`；选中任务但无活跃并发明细时
  显示 `（无并发连接）`（DIM 居中；右上角徽标仍显示 ` 0/y 项 `）。空态/无任务时
  面板不接收滚轮（指针悬停时滚轮透传给任务列表，§4.1.5）。

### 5.5 页脚（命令 chips + toast 区）

双行内容（外框 `BORDER` 暗色圆角框；总高 4 行 = 边框 2 + 内容 2；本轮需求
修订：行 1 常用命令图例 chips 恢复保留 + 行 2 toast 反馈保留）：

```
│  A 命令 · D 删除 · M 修改 · Q 退出 · H 帮助 │   ← 行 1：快捷命令 chips（§7.3）
│  ◆ toast 消息文本                          │   ← 行 2：toast 提示（§7.4）
```

**行内边距**（§4.3 S2）：两行内容左右各留 **2 列**空白（与其他 panel/弹窗
内容区同宽）——行 1 chips 与行 2 toast 起止一致，不顶格贴边框。

**行 1 快捷命令 chips**

- 五枚：`A 命令` / `D 删除` / `M 修改` / `Q 退出` / `H 帮助`，分隔符 ` · `
  （DIM2）；命令键 ACCENT 加粗、标签 FG。
- 鼠标左键点击与键盘快捷键**完全同口径**（§7.3）：按压反色高亮（ACCENT
  背景，同对话框按钮聚焦态色）、原地松开执行、拖出取消；400ms 点击余辉
  （快速点按在两帧之间也能看到点击效果）。
- 小终端（P7）：放不下的 chip 整个不渲染（不越界、不截断）。
- chips 是**可点击的命令入口**（P5 鼠标等价通道），不是提示文案——不适用
  P10「窗口不需要有提示信息」；快捷键完整说明仍收敛于 H 帮助窗口（P3，
  【全局】组「页脚命令」条目）。

**行 2 toast 提示**

- `◆ ` 前缀 + 黄色消息（§7.4）；无 toast 时该行留空。
- 鼠标点击通道字段：`footer_cmd_rects`（每帧回填命中矩形，不含分隔符）/
  `footer_press`（按压态）/ `footer_flash`（400ms 余辉）/ `run_footer_cmd`
  （与键盘同口径执行）；模态浮层打开时鼠标事件先交给浮层，各模态 Down
  一律清除 chip 按压态（模态期页脚不可达，P2）。

### 7.4 toast 反馈

- 位置：页脚行 2（toast 区，§5.5；行 1 为快捷命令 chips，本轮需求修订恢复）；样式 `◆ 消息`（黄色）。
- 时长：一般 3 秒自动消失；启动欢迎语 4 秒。
- 一次只显示最新一条（新 toast 覆盖旧 toast）。
- 典型文案：`已复制 url` / `已复制 校验码` / `已复制 失败原因` / `已复制 保存路径`（本轮需求修订新增后两者；字段值弹窗内按 Y 同口径） /
  `✂ 已断开连接 192.*.100（剩余 N 条）` /
  `仅 BT 任务支持断开并发连接（B）` / `⚠ 已完成任务不可修改` /
  `已清理 N 个已完成任务` / `⏸ 已暂停…` / `▶ 继续下载…` / `✓ 后期处理完成: …` /
  `✓ 已添加任务 #id: name（BT，已选 k/n 文件）`（phase2） /
  `✓ BT 任务已更新：k/n 文件 · 共 X（立即生效）`（phase2） /
  `⚠ 请至少选择一个要下载的文件（空格勾选）`（phase2） /
  `⚠ 仅处理第一行输入，其余 N 行已忽略`（phase2） /
  `补全目录：…` / `无匹配：<token>`（phase2 命令窗口补全）。
  操作类 toast 可带语义前缀符号（✂ 断开 / ⚠ 拒绝 / ⏸ 暂停 / ▶ 继续 / ✓ 完成）。

## 8. 任务状态系统

| 状态 | 徽标文案 | 颜色 | 页签归属 | 并发明细 |
|------|----------|------|----------|----------|
| 等待中（Queued） | `[等待中]` | YELLOW | 正在下载 | 无 |
| 下载中（Downloading） | `[下载中]` | LIGHT_BLUE | 正在下载 | **有** |
| 已暂停（Paused，含失败挂起） | `[已暂停]` | White | 正在下载 | 无 |
| 校验中（Verifying） | `[校验中]` | LIGHT_BLUE | 正在下载 | 无 |
| 后期处理中（PostProcessing） | `[后期处理中]` | LIGHT_BLUE | 正在下载 | 无 |
| 已失败（Failed） | `[已失败]` | RED | 正在下载 | 无 |
| 已完成（Completed） | `[已完成]` | GREEN | 已完成 | 无 |
| 做种中（Seeding） | `[做种中]` | MAGENTA | 已完成 | **有** |

- 页签计数：正在下载 = 非 `is_done` 状态数；已完成 = Completed + Seeding。
- 下载槽位 = 5（`MAX_DOWNLOAD_SLOTS`）；下载中与（未达上限的）已失败任务占用槽位；
  等待中任务按列表顺序排队获得槽位。
- 失败类别决定重试文案：Transient 自动重试（指数退避，Retry-After 优先）；
  Fatal / Verify「不自动重试」；Invalidated 断点作废从头下载。

## 9. 渲染管线与稳定性保障

| 机制 | 说明 |
|------|------|
| 事件循环 | tokio select：100ms 模拟 tick（ MissedTickBehavior::Skip）+ 键盘/鼠标/粘贴事件流；每循环 `terminal.draw` 一帧；按键仅响应 Press 事件（部分终端上下报都会上送的释放事件被过滤） |
| 图层 z-order | 每帧固定自底向上绘制：底层三/一面板 → 页脚 → 对话框 → pieces → 帮助（后绘覆盖先绘，§3.1）；下拉是对话框内的子覆盖层 |
| 覆盖层绘制 | 浮层开关/拖拽/位置变化由增量 diff 直接绘制，**不清屏**（旧版 FNV-1a 签名 → `terminal.clear()` 已退役：清屏瞬间整终端空白 = 打开窗口整屏闪烁）。**残影根因**（diff 跳过被覆盖的宽字符尾格）已由 `clip_wide_at_edges` 在缓冲区层根治，前后帧模型自洽后清屏不再需要；回归：`check_overlay_redraw.py`（翻转零清屏 + 角字符残影检测） |
| CJK 宽度 | 全部对齐/截断/命中用 `w()`（CJK 2 列）；`truncate` 截断加 `…`；`pad_right/pad_left` 按显示宽 |
| 浮层边界清扫 | `clip_wide_at_edges` 清除被浮层边框切开的宽字符半格 |
| 颜色强制 | `force_color_output(true)`：界面语义完全依赖配色，无视 `NO_COLOR` |
| 崩溃安全 | panic hook 先恢复终端再打印；退出统一走 `restore_terminal()` |
| 速度采样 | 1s 窗口 + 每秒采样 + EMA α=1/5（与生产 SpeedDisplay 同管线）；流量图独立双向 EMA + 自适应缩放 |
