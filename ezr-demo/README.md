# ezr-tui-demo（ezr-demo）

swarm-ezr2 仓库中 ezr-demo 子项目：Rust + ratatui 的终端 TUI 演示应用（下载器界面演示）。

## 快速运行

```bash
chmod +x bin/ezr-tui-demo
./bin/ezr-tui-demo
```

需使用支持鼠标事件与 ANSI 颜色的终端（xterm-256color 及以上）。

## 目录结构

- `bin/ezr-tui-demo` — 随包预编译的 release 二进制（x86-64 Linux, stripped；
  已随变更记录 12 重建，与当前源码一致；如需自行构建见「重新构建」）
- `src/` — 全部源码（`src/ui.rs` 布局与渲染、`src/app.rs` 交互与模拟器）
- `docs/` — 设计文档，含《ezr-demo UI界面及交互设计规范.md》（与实现同步维护）
- `scripts/` — 回归/验证脚本（见下）
- `Cargo.toml` / `Cargo.lock` — 构建清单

     不同 panel 复用同一组件获得完全相同的行为——**双线滑块 `═`（水平）/
     `║`（垂直）作为可滑动部分，在与面板边框同字形同粗细的单线轨道
     `─`/`│` 上滑动**，两端配 `←`/`→`、`↑`/`↓` 箭头（即 `←─═══─→` / `↑│║│↓`）
   - **滑块鼠标拖拽** = 比例滚动内容（滑块在单线轨道上滑动；拖拽反解与
     显示取整严格互逆）

     0.12s 周期）；**轨道点击/按住** = 朝点击方向整页滚动
   - **键盘方向键滚动**：面板聚焦时 ↑↓ 纵向（列表 = 选择跟随视口）、
     ←→ 横向（并发面板超宽列）

     「窗口拖拽」处理（移动窗口而非滚动内容）——现统一为拖滑块滚内容、
     拖空白处移窗口
   - **箭头留白（分轴向规则）**：水平箭头前后两侧各留 **1 格空白**（外侧
     靠边框线/角、内侧靠轨道），即 `╰ 空白 ← 空白 ═══─── 空白 → 空白 ╯`；
     垂直箭头**紧贴角与轨道、不留空白**（`╮↑│║│↓╯`）——垂直边框列保持
     连续（中断的竖线视觉上等同边框破损）且轨道更长（面板高 ≥ 6 即绘制，
     同等板高下轨道 +4 格）；内容可滚则滑块必可动（行程 ≥ 1，轨道 ≥ 2 格
     才绘制）
   - **箭头按压高亮（m3 修订）**：按下/按住 = **前景色换成滑块同款**
     （聚焦绿加粗，无背景色）；按住期间指针拖出箭头 = 取消高亮（连发不
     中断）、拖回恢复；松开后 400ms 余辉——快速单击也有一段可见的点击
     反馈
