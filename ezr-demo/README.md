# ezr-tui-demo（ezr-demo）

swarm-ezr2 仓库中 ezr-demo 子项目：Rust + ratatui 的终端 TUI 演示应用（下载器界面演示）。

## 快速运行

```bash
chmod +x bin/ezr-tui-demo
./bin/ezr-tui-demo
```

需使用支持鼠标事件与 ANSI 颜色的终端（xterm-256color 及以上）。

## 目录结构

- `bin/ezr-tui-demo` — 随包预编译的 release 二进制（x86-64 Linux, stripped）
- `src/` — 全部源码（`src/ui.rs` 布局与渲染、`src/app.rs` 交互与模拟器）
- `docs/` — 设计文档，含《ezr-demo UI界面及交互设计规范.md》（与实现同步维护）
- `scripts/` — 回归/验证脚本（见下）
- `Cargo.toml` / `Cargo.lock` — 构建清单

## 变更记录（相对上游）

1. **页脚双行重构（m2）**
   - 第一行：常用命令图例 `A 添加 · D 删除 · M 修改 · Q 退出 · H 帮助`，
     鼠标点击执行对应命令（按压反色高亮 + 400ms 余辉 = 点击效果，与键盘同口径）
   - 第二行：toast 提示独占一行（◆ 黄色）
2. **页脚左右内边距（m2 补丁）**
   - 两行内容左右各留 1 列空白，与头部面板右侧图区到右边框的留白同距；
     命中矩形随内容平移，点击语义不变
3. **并发列表滚动到底即停（m2 补丁，修复闪烁）**
   - 滚到底后继续下滚不再移动窗口、不再反复重绘；根因是滚轮事件未立即
     钳制 + 渲染层越界钳制过宽，现改为事件内钳制 + 渲染层「最后满窗」双重防线
4. **浮层翻转零清屏（修复打开新窗口整屏闪烁）**
   - 移除浮层翻转时的 `terminal.clear()` 全屏清屏（清屏瞬间整终端空白即闪烁）
   - 残影根因（diff 跳过被浮层覆盖的宽字符尾格）已由渲染层
     `clip_wide_at_edges` 在缓冲区层根治，前后帧模型自洽，清屏不再需要
5. **通用滚动条组件（m3）**
   - 新增 `src/scrollbar.rs`：全系统唯一的滚动条实现，不同 panel 复用同一
     组件获得完全相同的行为——**双线滑块 `═`（水平）/ `║`（垂直）作为可
     滑动部分，在与面板边框同字形同粗细的单线轨道 `─`/`│` 上滑动**，
     两端配 `←`/`→`、`↑`/`↓` 箭头（即 `←─═══─→` / `↑│║│↓`）
   - **滑块鼠标拖拽** = 比例滚动内容（滑块在单线轨道上滑动；拖拽反解与
     显示取整严格互逆）
   - **箭头鼠标点击** = 步进 1 单位；**按住不放自动连发**（0.4s 起振、
     0.12s 周期）；**轨道点击/按住** = 朝点击方向整页滚动
   - **键盘方向键滚动**：面板聚焦时 ↑↓ 纵向（列表 = 选择跟随视口）、
     ←→ 横向（并发面板超宽列）
   - **修复**：此前滚动条箭头均不可点击；pieces/帮助弹窗里拖滚动条被按
     「窗口拖拽」处理（移动窗口而非滚动内容）——现统一为拖滑块滚内容、
     拖空白处移窗口
   - **箭头留白（分轴向规则）**：水平箭头前后两侧各留 **1 格空白**（外侧
     靠边框线/角、内侧靠轨道），即 `╰ 空白 ← 空白 ═══─── 空白 → 空白 ╯`；
     垂直箭头**紧贴角与轨道、不留空白**（`╮↑│║│↓╯`）——垂直边框列保持
     连续（中断的竖线视觉上等同边框破损）且轨道更长（面板高 ≥ 6 即绘制，
     同等板高下轨道 +4 格）；内容可滚则滑块必可动（行程 ≥ 1，轨道 ≥ 2 格
     才绘制）
   - **箭头按压高亮（m3 修订）**：按下/按住 = **前景色换成滑块同款**
     （聚焦绿加粗，无背景色）；按住期间指针拖出箭头 = 取消高亮（连发不
     中断）、拖回恢复；松开后 400ms 余辉——快速单击也有一段可见的点击
     反馈
6. **并发连接面板：客户端 / 协议列 + 横向滚动条（m3）**
   - BT 任务新增 `客户端`（两字母缩写：QB/TR/LT/UT/DE/AR/RT/TX/AZ/XL）
     与 `协议`（TCP / uTP）两列置于**末尾**，列序为
     IP(11)/下载速度(8)/累计下载(8)/上传速度(8)/累计上传(8)/客户端(6)/协议(4)
   - 七列内容宽 59 列超出内框 → **底部横向滚动条**（`←─═══─→`，通用组件）+
     `←`/`→` 键横向滚动；HTTP 任务列序不变、无横向滚动条
   - 切换选中任务/协议时横向偏移归零重置

## 重新构建

```bash
cargo build --release
# 产物在 target/release/ezr-tui-demo
```

Rust stable 工具链即可；依赖见 Cargo.lock。
