## 1. 期目标

把 ezr-tui-demo 的界面与状态机从本地模拟数据切换到**真实 HTTP/HTTPS 下载内核**，交付日常可用的
终端下载器 MVP：完整链路「添加 → 探测 → 分块并发下载 → 断点续传 → 失败重试 → 校验 → 完成」，
支持会话持久化与崩溃恢复；UI 与交互和 demo 定稿基线保持一致。

## 2. 本期范围

### 2.1 范围内

- 协议：HTTP/1.1 与 HTTPS（含重定向跟随）。
- 下载内核：多并发分块（AIR2）、断点续传（sidecar 元数据）、自动重试与指数退避、
  完整性校验（MD5 / SHA-1 / SHA-224 / SHA-256 / SHA-384 / SHA-512 / Adler-32 七种算法，
  与 demo 定稿一致）、全局限速、HTTP(S) 代理。
- TUI 全部基线功能接入真实数据（模拟器移除）。
- 会话持久化（任务注册表）与崩溃恢复。
- CLI 启动参数添加任务；单实例运行保护。
- 交付平台与交付物：Linux x86_64 预编译二进制（macOS aarch64 / Windows x86_64 保证可编译运行，
  P1）；交付物含源码、预编译二进制与 README（使用说明与自动化验证方式，mission §5.4）。

### 2.2 范围外（本期不做）

- BT / 磁力链 / 做种（分期 02；「做种中」状态仅作枚举预留，界面不出现）。
- FTP / SFTP、HLS / DASH / M3U8、ED2K 等其他协议。
- 每任务限速与限速 TUI 控件（分期 03；本期仅全局限速，经配置/参数设置）。
- SOCKS5 代理（分期 03）。
- 剪贴板监听、浏览器接管、RPC 远程控制、订阅/批量导入（分期 03 候选）。

### 3.2 下载内核（HTTP）

| 编号 | 优先级 | 需求 |
|---|---|---|
| FR-01-10 | P0 | 任务开始时发送探测请求（携带 `Range: bytes=0-` 的 GET，或先 HEAD），获取 `Content-Length`、`Accept-Ranges`、`ETag`、`Last-Modified`；据此判定文件大小与「支持/不支持断点续传」（详情页如实显示）。 |
| FR-01-11 | P0 | **数据分块（定案，沿用 demo）**：块大小 HTTP 默认 **1 MB**（可配置，FR-01-71 键 `block_size_http`，D13）；总块数 y = ⌈文件大小 / 块大小⌉（末块不足整块吸收余数）；各连接从块队列动态领块，完成一块立即领取下一块（乱序完成）；实际并发 = min(设置并发, 剩余未完成块数)；队列临近结束时多余连接转「待命」。 |
| FR-01-12 | P0 | **不支持断点续传**（无 `Content-Length` 或服务器不响应 Range 请求）：自动降级为单并发整体下载；详情显示「不支持断点续传」；暂停后继续将从头下载（沿用 demo）。 |
| FR-01-13 | P0 | 分块写入：各块按自身偏移直接写入目标文件（并发写互不重叠）；下载中断后已下载块的字节保持有效，续传不重写已下载块。 |
| FR-01-14 | P0 | 重定向：最多跟随 10 次；以最终 URL 参与续传一致性比较（FR-01-22）。 |
