# QA 套件 · 01-tui-display TUI 展示与交互（期号 01）

> 对应规格：`project/features/01-tui-display.feature`（15 场景）。
> 端到端 UI 层验证：伪终端画面/配色单元格断言 + 按键/鼠标注入 + fixture 驱动真实状态。

## 环境前置

- 伪终端驱动：按键注入、鼠标事件注入（SGR 协议）、逐单元格画面与配色断言（参照 `ezr-demo/scripts/capture.py`、`verify_ezr.py`，配色断言需无视 NO_COLOR——产品强制彩色输出）。
- fixture 服务器（慢速门控维持「下载中」观察窗；多尺寸文件；中文文件名文件）。
- 终端尺寸可调（120×34 与 80×34 两档）；独立 HOME。
- 鼠标用例要求终端启用 SGR 鼠标协议；无鼠标环境该用例记 S 并内嵌判据。
