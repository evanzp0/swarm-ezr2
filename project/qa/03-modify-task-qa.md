# QA 套件 · 03-modify-task 任务修改对话框（期号 01 · v1.5/FR-01-87）

> 对应规格：`project/features/03-modify-task.feature`（8 场景）。
> 端到端 UI 层验证：按键驱动（m/Tab/Enter/Esc）+ 详情区活跃连接数观测 + fixture 代理日志 +
> 注册表文件观察 + 重启续传；不使用项目内部 API。

## 环境前置

- fixture 服务器（含足量多块文件，保证并发观测窗口）+ ezr-proxy 多实例。
- 独立 HOME；进程管理工具；PTY 驱动（pyte 伪终端口径，沿 QA 现行方法学）。
- 连接数观测口径：任务详情活跃连接行（或分块连接快照），采样间隔 ≥ 1s。

## 用例

| 用例 | 场景 | 操作 | 通过判据 |
|---|---|---|---|
| QA-MT-01 | 03-modify-task-01 | 按预填参数添加任务 → 选中按 m | 对话框四字段与任务当前值一致；焦点次序并发→算法→校验码→代理→确定→取消 |
| QA-MT-02 | 03-modify-task-02 | 下载中 1→4 与 4→1 各一轮 | 上调：活跃连接数下一调度周期升至 ≤4；下调：降至 ≤1；全程字节单调不减、任务不暂停 |
| QA-MT-03 | 03-modify-task-03 | 下载中直连→proxy-a、proxy-a→直连各一轮 | 切换后新请求出现在目标 proxy 日志；切直连后两日志不再增长；任务完成文件正确 |
| QA-MT-04 | 03-modify-task-04 | 改校验为正确/错误新值各一轮 | 完成校验按新值判定：正确→已完成+通过；错误→校验失败提示入详情 |
| QA-MT-05 | 03-modify-task-05 | 清空校验码确定 | 完成无校验直接已完成；详情无校验期望行 |
| QA-MT-06 | 03-modify-task-06 | SHA-256 配 8 位 hex 确定 | 对话框不关、任务无变化、校验码字段聚焦+提示；修正后可生效 |
| QA-MT-07 | 03-modify-task-07 | 已完成任务按 m | 无对话框；toast 提示不可修改 |
| QA-MT-08 | 03-modify-task-08 | 修改并发/校验/代理 → 立即 Q 退出 → 重启 | 四参数与修改后一致（详情+对话框预填）；续传/重试按新参数 |

## 通过准则

- 全部用例 P/F/S；S 内嵌环境判据（并发观测窗口不足等登记 S 并说明）。
- 「立即生效」判定（QA-MT-02/03）以 D19 口径为准：不要求在途请求/在途块被打断重连；
  并发下调允许块级过渡延迟（默认块 1 MB 秒级）。
- 修改落盘判定（QA-MT-08）允许注册表写入与退出间秒级窗口，但重启后必须读到新参数。
