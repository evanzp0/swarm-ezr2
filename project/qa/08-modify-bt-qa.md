# QA 套件 · 08-modify-bt 修改任务：BT 对话框（期号 02）

> 对应规格：`project/features/08-modify-bt.feature`（6 场景）。
> 需求依据：`project/mission/phase-02.md` FR-02-03/04。
> UI 基线：ezr-demo phase2 源码（78×24 / 焦点表 0–5 / 预填与确认口径 / toast 文案照录源码，
> specifier 逐条核证）。
> M 键守卫（D45）= state != Completed（demo 核证）——「做种中」BT 任务同样可打开修改。
> 端到端 UI 层验证：只用用户可达入口（TUI 按键/鼠标、磁盘产物观察、fixture 日志），
> 不进入项目内部 API。

## 环境前置

- 伪终端驱动：按键注入、画面捕获、toast/浮层断言。
- 本地 BT fixture（HTTP/UDP tracker + seeder peer）；一个下载中的多文件 BT 任务
  （9 文件种子、已完成部分 piece——通过控制 fixture 限速达成）。
- 独立 HOME（干净 `~/.ezr`）；独立保存目录 `/tmp/qadl`（用例间清空复位）。

## 用例

| 用例 | 场景 | 操作（用户可达入口） | 通过判据（可观察状态） |
|---|---|---|---|
| QA-MB-01 | 08-modify-bt-01 | BT 任务按 M；HTTP 任务按 M；已完成任务按 M；做种中任务按 M | BT → ` 修改任务：BT ` 78×24 居中 [✗]，布局九段（顶 padding/任务名/列表框 8 行/并发/代理/trackers/空行/按钮行/底 padding）、按钮 `[ 确定 ]  [ 取消 ]`、焦点在文件列表、列表框标题/按钮/统计与添加框同口径；HTTP → 仍开「修改任务：HTTP(S)」；已完成 → toast `⚠ 已完成任务不可修改` 无对话框；做种中 → 正常打开修改框（可改文件勾选/并发/代理，不改做种计时，D45） |
| QA-MB-02 | 08-modify-bt-02 | 打开修改框逐项观察 | 任务名静态行 `任务 「<name>」`（白粗、超宽截断）；文件勾选 = 任务当前状态（[x]/[ ]，目录默认收拢）；并发 = 当前值；代理 = 当前代理（不在选项表时追加兜底项）；trackers 预填任务持久 tracker 列表（每行一条） |
| QA-MB-03 | 08-modify-bt-03 | 取消 1 个未完成文件勾选 → 确定；重开勾回 → 确定 | toast 逐字 `✓ BT 任务已更新：<k>/<n> 文件 · 共 <size>（立即生效）`；total 重算、已下载钳制 ≤ 新 total、列表进度即时更新；被取消文件停止推进；勾回后补下且已落盘 piece 不重下（fixture 侧断点可观察） |
| QA-MB-04 | 08-modify-bt-04 | 全不选 → 确定；Esc / [✗] / [ 取消 ] 关闭 | toast `⚠ 请至少保留一个要下载的文件（空格勾选）`、焦点回列表不关窗；三种关闭通道均无修改生效 |
