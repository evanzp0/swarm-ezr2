# QA 套件 · 06-cmd-window 命令窗口（期号 02）

> 对应规格：`project/features/06-cmd-window.feature`（8 场景）。
> 需求依据：`project/mission/phase-02.md` FR-02-01/04/05、D44/D53/D55/D56/D59。
> UI 基线：ezr-demo phase2 源码（78×16 / 9 可视行 / 按钮行 = 内框底 −2 无空行——设计文档
> 「与文本框间空 1 行」与源码不符，QA 断言以源码与规格为准）。
> 分流三分（D44）：非 http 且非 .torrent path（含磁力链）与 .torrent 解析失败均走
> 「错误」窗口（66×7，D56）；帮助「输入内容」条目去磁力（D59）。
> 端到端 UI 层验证：只用用户可达入口（TUI 按键/鼠标、命令窗口输入、磁盘产物观察），
> 不进入项目内部 API。

## 环境前置

- 伪终端驱动：按键注入（含 kitty 键盘协议序列 `\x1b[13;2u` Shift+Enter、`\x1b[13;5u` Ctrl+Enter、
  ESC 前缀 Alt+Enter `\x1b\r`）、画面捕获、toast/浮层断言（参照 `ezr-demo/scripts/verify_phase2_ui.py`
  的注入与断言方式）。
- 独立 HOME（干净 `~/.ezr`）；独立保存目录 `/tmp/qadl`；本地 BT fixture（tracker + seeder）
  与预置目录 `/tmp/qatorrents`（含 .torrent 文件、子目录、隐藏文件供补全用例、
  **corrupt.torrent 损坏种子**（非法 bencode）与不存在路径用例）。
- `~` 展开用例以 QA 账户真实 HOME 预置目录。
