# QA 套件 · 01-retry-backoff 失败重试与退避（期号 01）

> 对应规格：`project/features/01-retry-backoff.feature`（10 场景）。
> 端到端 UI 层验证：TUI 状态/列表行文案断言 + fixture 故障注入 + 配置文件控制。

## 环境前置

- fixture 能力：按文件注入连接拒绝/超时/重置、指定 HTTP 状态码（403/404/408/429/500/503）、`Retry-After` 头、立即失败（无进展）模式、传输中途断连（有进展）模式、磁盘故障模拟（或以受限目录替代）。
- 伪终端驱动（列表行文案断言：重试计数、倒计时、「已达上限」「不自动重试」）；独立 HOME。
- 受限小容量目录（64MB tmpfs 或等效）用于磁盘预检用例。
- 时序纪律：倒计时断言采「秒级读数序列」，允许 ±1s 采样误差。

## 用例

| 用例 | 场景 | 操作 | 通过判据 |
|---|---|---|---|
| QA-RB-01 | 01-retry-backoff-01 | 逐一注入 6 类故障 | 详情失败原因行与 toast 文案与规格一致（网络错误子类/HTTP 状态码/磁盘错误） |
| QA-RB-02 | 01-retry-backoff-02 | 断连→重试有进展→再断连 | 列表行显示 `1/5`（有进展重置） |
| QA-RB-03 | 01-retry-backoff-03 | 持续无进展失败 | 计数 2/5→5/5；达上限停止自动重试、释放槽位、显示「已达上限」；R 重置 1（AC-3） |
| QA-RB-04 | 01-retry-backoff-04 | 持续无进展失败观察倒计时 | 读数序列 8→16→32→60→60（封顶）；每次自动重试 |
| QA-RB-05 | 01-retry-backoff-05 | 503+`Retry-After: 10` / `: 60` / `: 90` | 倒计时显示 10s / 60s / 90s（优先于退避） |
| QA-RB-06 | 01-retry-backoff-06 | 503+`Retry-After: 120` | 倒计时显示 120s（不回退指数退避） |
| QA-RB-07 | 01-retry-backoff-07 | 403 / 404 | 「不自动重试」；无倒计时；不占槽；R 可重试 |
| QA-RB-08 | 01-retry-backoff-08 | 408 / 429 / 500 / 连接重置 | 均退避自动重试且占槽 |
| QA-RB-09 | 01-retry-backoff-09 | 受限目录下载 100MB | 获槽即失败「磁盘空间不足」；停等；R 可重试 |
| QA-RB-10 | 01-retry-backoff-10 | 配置 `auto_retry=false` 后注入网络错误 | 直接停等显示「不自动重试」；R 可重试；重试后失败仍停等 |

## 通过准则

- 全部用例 P/F/S；S 内嵌环境判据。QA-RB-03 对应 AC-3 核心（计数连续性+达上限语义）。
